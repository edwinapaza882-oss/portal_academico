# Portal Académico - Flask

Este es un proyecto web desarrollado en **Python** con el microframework **Flask**, que simula un sistema de gestión de portal estudiantil. Incluye autenticación de usuarios, protección de rutas con sesiones, persistencia con cookies y renderizado dinámico con Jinja2.

## Características
* **Autenticación:** Sistema de login simulado con credenciales predefinidas.
* **Sesiones:** Control y protección de acceso a rutas privadas (`/perfil`).
* **Cookies:** Almacenamiento de preferencias de usuario (`usuario_preferido`).
* **Jinja2:** Renderizado de plantillas HTML y evaluación dinámicas de cupos en la vista de cursos.
